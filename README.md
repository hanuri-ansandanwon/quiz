아이들이 집에서 휴대폰으로 푸는 어휘 퀴즈예요. 로그인 없이 주소만 열면 돼요.

## 어휘 퀴즈 (`index.html`)

단계(어휘1·어휘2·독서1·독서2·논리1·논리2·소1·소2)를 고르고, 차시를 고른 뒤 **낱말 카드 / 뜻 보고 낱말 고르기 / 빈칸 채우기** 중 하나로 공부해요. 한 번에 10문제, 끝나면 틀린 낱말만 다시 풀 수 있어요.

- 월호별로 올려요 (12월호, 1월호 …). **최근 2개 월호만** 두고, 새 월호를 올릴 때 가장 오래된 월호를 지워요 (예: 2월호를 올리면 12월호 삭제). 3개 이상이면 자동 점검에서 알려 줘요. 처음 화면에서 월호를 고르고, 가장 최근 월호가 먼저 열려요.
- 단계별 주소 (QR코드로 만들어 숙제지에 붙이기): `https://hanuri-ansandanwon.github.io/quiz/?level=어휘1` → 가장 최근 월호. 지난 월호는 `?month=2026-12&level=어휘1`
- 낱말 바꾸기: `data/vocab.js` — 월호(`"2027-01": { label: "2027년 1월호", levels: {…} }`) → 단계 → 차시 → 낱말. `w` 낱말, `m` 뜻, `p` 책 쪽수, `h` 한자, `u` 음과 훈, `c` 갈래(한자성어·속담·어휘), `ex` 예문(빈칸 정답을 `[ ]`로 감싸요. 예: `숙제를 [미적미적] 미루다가 밤이 됐어.`). 예문이 없는 낱말은 빈칸 문제에 나오지 않아요.

## 중학 한자어·사자성어 (`hanja.html`)

비밀번호로 잠긴 페이지예요. 낱말은 `data/hanja.enc.js`에 암호화되어 있어서, 바꿀 때는 Claude에게 부탁해요.

- `hanja.html?hoe=5` → 어휘5를 바로 열기(숙제 QR용) · `hanja.html?all=1` → 모든 단계 열기(선생님 확인용)

## 올리는 방법

`main`에 올리면 GitHub Actions가 `scripts/check.mjs`로 점검하고, 통과하면 사이트에 반영돼요 (1~2분). 처음 한 번 **Settings → Pages → Source를 GitHub Actions**로 바꿔 두어야 해요.

## 다른 지부에서 쓰려면

이 저장소를 통째로 가져가면 돼요 (오른쪽 위 **Fork**, 또는 **Code → Download ZIP** 후 내 저장소에 올리기). 내 저장소의 **Settings → Pages → Source를 GitHub Actions**로 바꾸면 `https://내아이디.github.io/저장소이름/` 주소가 생겨요.
